# LiteLoader 1.12.2 纯客户端脚手架

LiteLoader 以客户端为主的工程形态、**无 Gradle**。用 MCP/IDE 编译即可。混合 Forge 工程见 `../hybrid/`。

> ⚠️ 「纯客户端」是**本 scaffold 的工程形态**（只出客户端侧入口），不是对 LiteLoader 本身的定性：上游源码另有 dedicated-server 通道（`LiteLoaderTweakerServer` / `ServerPluginChannels`），但服务端权限面是半成品（`PermissionsManagerServer` 空实现），本仓不为它出服务端脚手架。见 `../../AGENTS.md` 首段。
