# Minecraft 1.21.x 版本变更

> 本文件记录从 Minecraft 1.20.x 到 1.21.x 的关键变更，适用于 Fabric 1.21.11。

## 1.21.0 主要变更

### 网络通信 API 变化（重要）

1.21.x 对网络通信系统进行了重大重构：

| 旧方式（1.20.x） | 新方式（1.21.x） |
|------|------|
| `FabricPacket` 接口 | `CustomPayload` 接口 |
| `Identifier` 基于的注册 | `PayloadTypeRegistry` + `PacketType` |
| `Packet` 类 | `CustomPayload` record |

**新网络通信示例**：

```java
// 1.21.x 方式
public record MyPayload(int data) implements CustomPayload {
    // 注册 ID
    public static final CustomPayload.Id<MyPayload> ID = 
        new CustomPayload.Id<>(new Identifier("modid", "my_packet"));
    
    // 编码
    @Override
    public void write(FriendlyByteBuf buf) {
        buf.writeInt(this.data);
    }
    
    // 解码
    public static MyPayload read(FriendlyByteBuf buf) {
        return new MyPayload(buf.readInt());
    }
}

// 在初始化时注册
PayloadTypeRegistry.c2s().register(MyPayload.ID, MyPayload::read);
PayloadTypeRegistry.s2c().register(MyPayload.ID, MyPayload::read);
```

### Attachment API（替代 Capability）

1.21.x 移除了旧版 Capability API，统一使用 Attachment API：

```java
// Attachment 注册
public static final Key<MyData> MY_DATA = Key.create(
    Registries.ATTACHMENT_TYPE, 
    new Identifier("modid", "my_data")
);

// 获取/设置
entity.getData(MY_DATA);           // 获取
entity.setData(MY_DATA, data);    // 设置
```

### 数据生成器变化

- `LootTableProvider` 略有调整
- `FabricRecipeProvider` 保持类似接口
- `TagProvider` API 可能有细微变化

## 通用注意事项

### Fabric 开发注意点

- **Yarn 映射版本**：每个 MC 版本需要对应版本的 Yarn 映射
- **Fabric API 版本**：Fabric API 0.200.x+build.3 for 1.21.x
- **Mixin 兼容性**：Mixin 版本需要与 MC 版本兼容
- **Loom 版本**：1.4-SNAPSHOT 支持 1.21.x
- **Java 版本**：1.21.x 必须使用 Java 21

### 数据包兼容性

- `type` 字段仍然是**必需**的
- pack_format 34 适用于 1.21.x
- Attachment API 完全替代 Capability

## 升级建议

1. **测试优先**：每次 MC 版本升级前，先在小规模项目中测试
2. **Java 版本**：确保使用 Java 21
3. **映射更新**：同时更新 Yarn/Parchment 映射版本
4. **API 更新**：Fabric API 也需要对应版本升级
5. **网络代码**：如果使用网络通信，需要完全重写为新 API
