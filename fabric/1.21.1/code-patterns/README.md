# Fabric Code Patterns

本目录包含 Fabric 1.21.1 模组开发的代码模式参考。

## 目录

- [01-block-patterns.md](01-block-patterns.md) - 方块开发模式
- [02-item-patterns.md](02-item-patterns.md) - 物品开发模式
- [03-entity-patterns.md](03-entity-patterns.md) - 实体开发模式
- [04-mixin-patterns.md](04-mixin-patterns.md) - Mixin 使用模式
- [05-fabric-api-patterns.md](05-fabric-api-patterns.md) - Fabric API 使用模式
- [06-datagen-patterns.md](06-datagen-patterns.md) - 数据生成模式

## 使用方式

这些模式文件提供了常用代码模式的参考实现。当开发新功能时，可以查阅对应的模式文件获取示例代码。

## 版本兼容性

这些模式针对 **Fabric 1.21.1** 编写，可能不适用于其他版本。
