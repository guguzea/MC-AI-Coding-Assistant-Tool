# 1.19.x → 1.20.x 版本变化

## 重大变化

### Registry 系统变化

1.19.x 之后，Registry 系统保持稳定，但有一些 API 变化：

```java
// ✅ 1.20.x 推荐方式
Registry.register(Registries.ITEM, new Identifier(MOD_ID, "my_item"), myItem);

// ❌ 过时方式（仍可工作，但不推荐）
Registry.register(Registries.ITEM, new Identifier(MOD_ID, "my_item"), myItem, DustItemGroupKey.INSTANCE);
```

### 网络系统变化

1.19.x 引入了一些网络 API 变化：

```java
// ✅ 1.20.x 方式
PayloadTypeRegistry.playC2S().register(MyPacket.ID, MyPacket.CODEC);
PayloadTypeRegistry.playS2C().register(MyPacket.ID, MyPacket.CODEC);
```

### Data Generation 变化

1.19.x 引入了一些 DataGen API 变化：

```java
// ✅ 1.20.x 方式：使用 RegistryWrapper.WrapperLookup
public class MyProvider implements DataStreamOutputSupplier.Writer {
    @Override
    public void generate(RegistryWrapper.WrapperLookup registries,
                         DataGenerator.GeneratorOutput output,
                         ExistingFileHelper existingFileHelper) {
        // ...
    }
}
```

## 常见迁移问题

### 编译错误：找不到类/方法

**解决方案**：
1. 更新 Yarn 映射版本
2. 检查 API 是否已被移除
3. 查看 [Fabric Wiki](https://fabricmc.net/wiki/documentation) 获取最新 API

### 资源文件问题

1.19.x 后，资源包格式保持稳定，但仍需注意：

```json
// pack.mcmeta
{
  "pack": {
    "pack_format": 34,  // 1.20.2+
    "description": "My Mod"
  }
}
```

## Java 版本变化

| Minecraft 版本 | 最低 Java 版本 | 推荐 Java 版本 |
|---------------|---------------|---------------|
| 1.18.x | Java 17 | Java 17 |
| 1.19.x | Java 18 | Java 18 |
| 1.20.x | Java 17 | Java 17/21 |
| 1.21.x | Java 21 | Java 21 |

## Loom 版本

确保使用与 Minecraft 版本兼容的 Loom 版本：

```groovy
plugins {
    id 'fabric-loom' version '1.3-SNAPSHOT'  // 1.20.4+
}
```
