# 1.19.x → 1.20.x 版本变化

## 重大变化

### Registry 系统变化

1.19.x 之后，Registry 系统保持稳定，但有一些 API 变化：

```java
// ✅ 1.20.x 推荐方式
Registry.register(Registries.ITEM, new Identifier(MOD_ID, "my_item"), myItem);

// ❌ 过时方式（仍可工作，但不推荐）
Registry.register(Registries.ITEM, new Identifier(MOD_ID, "my_item"), myItem, DustItemGroupKey.INSTANCE);
```

### 网络系统变化

1.20.1–1.20.4 Yarn 仍是 `ServerPlayNetworking.registerGlobalReceiver(Identifier, ...)` + `PacketByteBuf`。
`PayloadTypeRegistry.playC2S()` / `CustomPayload` 是 **1.20.5 / 1.21+**，不要写进 1.20.1 规则。

### Data Generation 变化

1.17+ 入口是 `DataGeneratorEntrypoint` + `fabric-datagen`。1.19.4+ 用 `generator.createPack()` 再 `pack.addProvider`。

```java
public class ExampleModDataGenerator implements DataGeneratorEntrypoint {
    @Override
    public void onInitializeDataGenerator(FabricDataGenerator generator) {
        FabricDataGenerator.Pack pack = generator.createPack();
        pack.addProvider(MyRecipeProvider::new);
    }
}
```

不要 `DataStreamOutputSupplier.Writer` / `ExistingFileHelper` / `init_data`。

## 常见迁移问题

### 编译错误：找不到类/方法

**解决方案**：
1. 更新 Yarn 映射版本
2. 检查 API 是否已被移除
3. 查看 [Fabric Wiki](https://fabricmc.net/wiki/documentation) 获取最新 API

### 资源文件问题

1.19.x 后，资源包格式保持稳定，但仍需注意：

```json
// pack.mcmeta
{
  "pack": {
    "pack_format": 34,  // 1.20.2+
    "description": "My Mod"
  }
}
```

## Java 版本变化

| Minecraft 版本 | 最低 Java 版本 | 推荐 Java 版本 |
|---------------|---------------|---------------|
| 1.18.x | Java 17 | Java 17 |
| 1.19.x | Java 18 | Java 18 |
| 1.20.x | Java 17 | Java 17/21 |
| 1.21.x | Java 21 | Java 21 |

## Loom 版本

确保使用与 Minecraft 版本兼容的 Loom 版本：

```groovy
plugins {
    id 'fabric-loom' version '1.3-SNAPSHOT'  // 1.20.4+
}
```
