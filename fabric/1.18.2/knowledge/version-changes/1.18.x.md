# Minecraft 1.18.x 版本变更

> 本文件记录从 Minecraft 1.17.x 到 1.18.x 的关键变更，适用于 Fabric 1.18.2。
>
> **重大变更：Caves & Cliffs 更新（第1部分）** — 1.18.x 是 Minecraft 历史上最深刻的世界生成变革。

## 1.18.0 主要变更

### 世界高度变化（最关键）

| 对比项 | 1.17.x | 1.18.x |
|--------|--------|--------|
| 最低高度 | Y=0（地表 Y=62）| Y=-64（地表 Y=0）|
| 最高高度 | Y=255 | Y=319 |
| 高度范围 | 256 方块 | 384 方块 |
| 生物群系 | Y=0-255 | Y=-64-319 |

**对模组开发的影响：**
- 世界高度常量已更改：`World.MAX_HEIGHT = 320`，`World.MIN_Y = -64`
- 高度分段的代码需要重新审查（悬崖、山洞、深渊）
- 噪音生成器配置完全重写
- 原版生物群系分布有大幅变化

### 生物群系 API 变化

- `Biome#getCategory()` → `Biome.getCategory()`（静态方法）
- `BiomeAPI` 替换为 `Registries.BIOME`
- 生物群系注册改用 `Registry.register()`
- 深渊（deep dark）、繁花（flower forest）等新生物群系加入

### 世界生成器重写

- `ChunkGenerator` 接口大幅变化
- `NoiseGenerator` 系列类几乎全部重构
- `SurfaceBuilder` 替换为 `SurfaceRuleManager`
- 噪声设置（NoiseParameters）使用新版格式

### 技术变更

| 变更 | 说明 |
|------|------|
| Registry 改进 | DeferredRegister 全面可用 |
| 配置文件格式 | HOCON 配置支持 |
| 数据包格式 | `pack_format` 变为 8 |
| 内置标签 | 新增大量 `minecraft:` 标签 |

## 1.18.2 变更

| 变更 | 说明 |
|------|------|
| 修复洞穴生成 | 某些噪声配置导致洞穴过多/过少 |
| 修复深渊生成 | Deep Dark 生物群系调整 |
| 繁花森林 | 花朵生成密度修复 |
| 绿维特克 | 绿维特克（glow lichen）生成调整 |

## 通用注意事项

### Fabric 开发注意点

- **Yarn/Parchment 映射**：1.18.x 使用 1.18.2 对应版本（如 `1.18.2+build.4`）
- **Fabric API 版本**：使用 `0.79.x+1.18.2` 系列
- **Mixin 版本**：`0.8.x` 支持 1.18.x
- **Loom 版本**：`0.11.x` 支持 1.18.x
- **Java 版本**：需要 Java 17

### 数据包兼容性

- `pack_format` 必须为 **8**
- 生物群系 JSON 使用新版格式
- 维度类型 JSON 有变化
- 噪声设置 JSON 格式完全不同

### 升级建议

1. **Caves & Cliffs 变更巨大**：任何依赖世界高度或生物群系分布的代码都需要审查
2. **使用 Parchment**：1.18.2 有良好 Parchment 文档，优先使用
3. **测试高度边界**：确保模组在 Y=-64 到 Y=319 范围内正常工作
4. **生物群系注册**：改用 `DeferredRegister<Biome>` 而非旧方式
