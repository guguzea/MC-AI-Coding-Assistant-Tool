# Minecraft 1.18.x 版本变更

> 本文件记录从 Minecraft 1.17.x 到 1.18.x 的关键变更，适用于 Fabric 1.18.2。
>
> **重大变更：Caves & Cliffs 更新（第1部分）** — 1.18.x 是 Minecraft 历史上最深刻的世界生成变革。

## 1.18.0 主要变更

### 世界高度变化（最关键）

| 对比项 | 1.17.x | 1.18.x |
|--------|--------|--------|
| 最低高度 | Y=0（地表 Y=62）| Y=-64（地表 Y=0）|
| 最高高度 | Y=255 | Y=319 |
| 高度范围 | 256 方块 | 384 方块 |
| 生物群系 | Y=0-255 | Y=-64-319 |

**对模组开发的影响：**
- 世界高度常量已更改：`World.MAX_HEIGHT = 320`，`World.MIN_Y = -64`
- 高度分段的代码需要重新审查（悬崖、山洞、深渊）
- 噪音生成器配置完全重写
- 原版生物群系分布有大幅变化

### 生物群系 API 变化

- `Biome#getCategory()`：1.18.2 Yarn 中 `Biome`（`net/minecraft/world/biome/Biome`）上仍有两个 `getCategory` 重载（`()Lcbr$b;` 与 `(Lgs;)Lcbr$b;`），返回 `Biome` 的嵌套类型；旧稿「改成静态方法」的断言无证据（yarn tiny 不记 static，且 1.18.2 无 `BiomeCategory` 类）。证据：`data/fabric_1.18.2/mappings/yarn-1.18.2+build.4-tiny.gz` 行 `METHOD	cbr	()Lcbr$b;	t	method_8688	getCategory`
- `Registries.BIOME` 在本档语料中不可核实：yarn 1.18.2 tiny 里 `net/minecraft/util/registry/Registries` 类 0 命中；可核实的注册表常量是 `BuiltinRegistries.BIOME`（`CLASS	ij	net/minecraft/class_5458	net/minecraft/util/registry/BuiltinRegistries` + `FIELD	ij	Lhb;	i	field_25933	BIOME`）。旧名 `BiomeAPI` 语料 0 命中（`TODO(未核实)`：其所属版本无法由本档裁决）
- 生物群系注册：`Registry.register(...)`（同档已核实写法见 `.cursor/rules/01-registry.mdc:22`、`knowledge/antipatterns/registry.md:71`）
- 新生物群系：`TODO(未核实)` —— 「深渊（deep dark）」「繁花（flower forest）」在 `data/fabric_1.18.2/**` 全文 0 命中，本档无一手语料可裁决它们属哪个 MC 版本

### 世界生成器重写

以下四条按本档与邻档 yarn tiny 的**类名差分**核实（`data/fabric_1.17.1/mappings/yarn-1.17.1+build.65-tiny.gz` 6107 个 CLASS 行 对 `data/fabric_1.18.2/mappings/yarn-1.18.2+build.4-tiny.gz` 6391 个 CLASS 行）。方法签名层面的变化未取证。

- `ChunkGenerator`：两版 FQCN 同为 `net/minecraft/world/gen/chunk/ChunkGenerator`（另有 `ChunkGeneratorSettings`），「接口大幅变化」属签名层断言，yarn tiny 类名差分不能证实也不能否证 —— `TODO(未核实)`，需 `get_minecraft_source` 反编译比对
- 噪声/密度机器全新：`net/minecraft/world/gen/densityfunction/`（`DensityFunction` 等）1.18.2 命中 **48** 个类，1.17.1 **0 命中**；1.17.1 有的 `NoiseChunkGenerator$NoodleCavesSampler`、`NoiseChunkGenerator$OreVeinSource` 在 1.18.2 已消失。旧稿「`NoiseGenerator` 系列类几乎全部重构」中的 **`NoiseGenerator` 类两版都 0 命中**（yarn 从未有该裸类名），按类名不成立
- 地表规则：`SurfaceBuilder`（`net/minecraft/world/gen/surfacebuilder/SurfaceBuilder`，`class_6724` 系）**1.17.1 与 1.18.2 都在**，没有被替换；1.18.2 新增的是同包内的 `MaterialRules`（含嵌套共 **38** 类）与 `VanillaSurfaceRules`（两者 1.17.1 均 0 命中）。旧稿「替换为 `SurfaceRuleManager`」里的 **`SurfaceRuleManager` 在本档 yarn 语料 0 命中**，是 mojmap/Forge 侧名字，禁止照抄进 Fabric 正文
- 噪声设置：`NoiseParameters` 裸类名两版都不存在。1.18.2 可核实的名字是 `world/gen/noise/BuiltinNoiseParameters`、`world/gen/noise/NoiseParametersKeys`、`util/math/noise/DoublePerlinNoiseSampler$NoiseParameters`；1.17.1 侧对应的是 `world/biome/source/MultiNoiseBiomeSource$NoiseParameters`

### 技术变更

| 变更 | 说明 |
|------|------|
| Registry 改进 | Fabric 侧仍是 `Registry.register(...)`；`DeferredRegister` 属 Forge/NeoForge，1.18.2 语料中 0 命中（yarn tiny + `mcp-server/data/loader-api-summaries/1.18.2-fabric-api.json`），旧稿「DeferredRegister 全面可用」为串档 |
| 配置文件格式 | Fabric Loader / Fabric API 不带配置文件格式；本档配置方案是第三方库（`scaffold/build.gradle:33` 的注释示例行给出 Cloth Config `9.0.2+1.18.2`（默认不启用））。旧稿「HOCON 配置支持」在 1.18.2 语料中 0 命中，属 Forge 侧串档 |
| 数据包格式 | 数据包 `pack_format` = **9**，资源包 = **8**（本档 `knowledge/common/datapack-format.md:7-8`；`forge/1.12.2/knowledge/common/datapack-format.md:20` 跨版本对照表引官方 1.18.2-40.3.0 MDK `forge:data_pack_format: 9`）。旧稿写 8 = 把资源包数值当成了数据包 |
| 内置标签 | 新增大量 `minecraft:` 标签 |

## 通用注意事项

### Fabric 开发注意点

- **Yarn/Parchment 映射**：1.18.x 使用 1.18.2 对应版本（如 `1.18.2+build.4`）
- **Fabric API 版本**：使用 `0.77.x+1.18.2` 系列（本档一致钉值：`scaffold/gradle.properties:5` = `0.77.0+1.18.2`、`AGENTS.md:175` = `0.77.x`、`knowledge/antipatterns/gradle.md:51`、`:59`、`scaffold/README_AI.md:43`；旧稿 `0.79.x+1.18.2` 在本档仅此一处、无任何同档佐证，已收口）
- **Mixin 版本**：`0.8.x` 支持 1.18.x（`TODO(未核实)`：本档语料无 Mixin/sponge-mixin 版本号出处）
- **Loom 版本**：本档并存两个钉值——文档正文 `0.14.46`（`.cursor/rules/00-project-setup.mdc:107`、`knowledge/antipatterns/gradle.md:41`、`knowledge/porting/fabric-to-forge.md:26`、`knowledge/porting/forge-to-fabric.md:29`）vs 可构建 scaffold `1.0.18`（`scaffold/build.gradle:2`，其 `gradle/wrapper/gradle-wrapper.properties:3` 注明「Loom 1.0.18 配对 Gradle 8」）。旧稿 `0.11.x` 在本档 0 佐证，已删；正解归属见台账「需要用户定夺」
- **Java 版本**：需要 Java 17

### 数据包兼容性

- 数据包 `pack_format` 必须为 **9**；资源包 `pack_format` 为 **8**（`knowledge/common/datapack-format.md:7-8`）。`scaffold/src/main/resources/pack.mcmeta` 写的是资源包描述文件 → `"pack_format": 8` 正确，不要按数据包改成 9
- 生物群系 JSON 使用新版格式
- 维度类型 JSON 有变化
- 噪声设置 JSON 格式完全不同

### 升级建议

1. **Caves & Cliffs 变更巨大**：任何依赖世界高度或生物群系分布的代码都需要审查
2. **使用 Parchment**：1.18.2 有良好 Parchment 文档，优先使用
3. **测试高度边界**：确保模组在 Y=-64 到 Y=319 范围内正常工作
4. **生物群系注册**：用 `Registry.register(...)`（同档已核实写法见 `.cursor/rules/01-registry.mdc:22`）；`DeferredRegister` 是 Forge/NeoForge 类，1.18.2 的 yarn tiny 与 fabric-api jar 摘要均 0 命中，禁止套用
