> 本文件 2026-09-11 新建（用户裁定「补 1.21.x 纪要」）。此前本档 `pack.meta.json` 的 `gaps.knowledge` 写着「本档语料无可核实主题页可支撑更多短文」——该措辞过强并已改：本档语料**有** `develop_porting_index.md`（36 行），只是其正文 = 改构建脚本三步 + 一组站外链接，据以写迁移细节须取外网。本文件因此**只用仓内语料与小映射表**，未取任何站外页。

> 证据面：`data/fabric_1.21.4/fabric-docs/1.21.4/`（processed 58 页 / raw 51 页）、基线 `data/fabric_1.21.1/`（raw 45 页）、两版 `mappings/yarn-*-tiny.gz`。

## 1. 官方迁移口径

- 本档语料的迁移基线由该页自己声明为 **1.21.1 → 1.21.4**：CORPUS `data/fabric_1.21.4/fabric-docs/1.21.4/processed/develop_porting_index.md:13`。
- 该页「Updating the Code」一节（`:25`）不给 API 清单，只把细节外链出去：Fabric blog `:31`、Minecraft 官方博客 `:32`、Minecraft Wiki `:33`、slicedlime 视频 `:34`、NeoForge 1.21.3→1.21.4 primer `:35`。⇒ **本仓不据此写任何方法名**；要 API 级细节须用户自己开那些页，或走 `search_fabric_docs version=1.21.4` / 本档 tiny。

## 2. 构建脚本（该页唯一给出的可执行步骤）

CORPUS 同页 `:21-23`，三条逐字：

1. `./gradlew wrapper --gradle-version latest`
2. 抬 Minecraft / Fabric Loader / Fabric Loom / Fabric API 版本，推荐改 `gradle.properties`；组件推荐版本看 fabricmc.net/develop
3. IDE 刷新，或 `./gradlew --refresh-dependencies` 强清缓存

> 本仓不代跑 Gradle（人在环）。另注：本档 `scaffold/` **无 wrapper 三件套**，第 1 条命令在此模板上跑不了 —— 见 `pack.meta.json` 的 `scaffold.gaps`。

## 3. 语料覆盖差：1.21.4 新出的专题入口

`raw/` 51 页 vs 1.21.1 的 45 页；**只在 1.21.4 出现 6 页**（1.21.1 独有 0 页 = 真子集关系成立）：

`develop_networking` · `develop_loom_index` · `develop_loom_fabric-api` · `develop_loom_options` · `develop_loom_production-run-tasks` · `develop_data-generation_block-models`

- **networking 在本仓首次有官方专页**：1.21.1 档 45 页里没有 `develop_networking`（该缺口在 `fabric/1.21.1/knowledge/version-changes/1.21.x.md` 里已登记）→ 1.21.4 起可直接 `search_fabric_docs version=1.21.4 query=networking`。
- **loom 一次成族**（index + fabric-api + options + production-run-tasks）= 本版起构建插件本身成为文档专题。

## 4. Yarn 名字实测（本区间的两处结构性变化）

- **配方生成整包新增**：`net/minecraft/data/recipe/` 在 1.21.1 tiny 里 **0** 个 CLASS，1.21.4 里 **18** 个 —— 含 `ShapedRecipeJsonBuilder`、`ShapelessRecipeJsonBuilder`、`CraftingRecipeJsonBuilder`、`CookingRecipeJsonBuilder`、`StonecuttingRecipeJsonBuilder`、`SmithingTransformRecipeJsonBuilder`、`SmithingTrimRecipeJsonBuilder`、`TransmuteRecipeJsonBuilder`、`ComplexRecipeJsonBuilder`、`RecipeExporter`、`RecipeGenerator`、`VanillaRecipeGenerator`。⇒ 「配方 JSON builder 从别处搬进 `data/recipe/`」是本区间对 datagen 代码影响最大的一条；具体旧位置本档不下断言（未逐名对照）。
- **注册表 / 标签加载重构**：`net/minecraft/registry/` 119 → 123。仅 1.21.4：`ReloadableRegistries$ReloadResult`、`RegistryLoader$ElementsAndTags`、`RegistryKeyedValue`、`Registry$PendingTagLoad`、`SimpleRegistry$TagLookup`、`tag/TagGroupLoader$RegistryTags`、`tag/TagGroupLoader$EntrySupplier`；仅 1.21.1：`tag/TagManagerLoader`、`tag/TagManagerLoader$RegistryTags`、`tag/TagPacketSerializer$Loader`、`ReloadableRegistries$ReloadableWrapperLookup`、`Registry$2`、`RegistryWrapper$WrapperLookup$2`。⇒ **`TagManagerLoader` 这个名字在 1.21.4 tiny 里不存在**，别照 1.21.1 的记忆写它。

复现（本仓根执行；两版各一次）：

```bash
u() { zcat data/fabric_$1/mappings/yarn-$2-tiny.gz | awk -F'\t' '$1=="CLASS"{print $NF}' | sort -u; }
u 1.21.4+build.8  | grep -c '^net/minecraft/data/recipe/'    # 18
u 1.21.1+build.3  | grep -c '^net/minecraft/data/recipe/'    # 0
u 1.21.4+build.8  | grep -x  'net/minecraft/registry/tag/TagManagerLoader' ; echo $?   # 无输出
```
