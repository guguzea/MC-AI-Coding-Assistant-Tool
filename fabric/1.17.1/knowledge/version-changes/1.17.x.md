# Minecraft 1.17.x 版本变更

> 本文件记录从 Minecraft 1.16.x 到 1.17.x 的关键变更，适用于 Fabric 1.17.1。

## 1.17.0 主要变更

### 新增内容

| 内容 | 说明 |
|------|------|
| Caves & Cliffs Part I | 新洞穴层、新方块（铜、紫水晶、滴水石）、山羊等 |
| World height 准备 | 世界高度相关内部改动；完整扩高在 1.18 |
| Goat / Glow Squid / Axolotl | 新增生物 |
| Copper / Amethyst / Tuff | 新增矿物与装饰方块 |
| Bundle（实验） | 物品束在数据包实验开关下可用 |

### 技术变更

| 变更 | 说明 |
|------|------|
| Java 16 | 本档工程用 Java 16（不要用 1.16.5 的 Java 8 假设） |
| `Registry` 仍是静态字段 | `Registries` 枚举是 **1.19.3+**；1.17.x 继续 `Registry.ITEM` |
| `addDrawableChild` | Screen 用 `addDrawableChild`，不要 `addButton`（那是 1.16） |
| `LiteralText` | 文本仍是 `LiteralText` / `TranslatableText`，不要 `Text.literal`（1.19.3+） |
| DataGenerator | 1.17+ 原版 datagen 可用；Fabric 用 fabric-datagen（版本随 Fabric API） |
| Y 轴内部 | 高度相关方法签名有变，移植时对一下 `query_api` / Yarn javadoc |

## 1.17.1 变更

| 变更 | 说明 |
|------|------|
| 稳定性补丁 | 1.17 线的维护版，模组档通常锁 1.17.1 |

## 通用注意事项

### Fabric 开发注意点

- **Yarn 映射版本**：锁 1.17.1 对应 Yarn，不要混用 1.16 / 1.18 映射名
- **Fabric API 版本**：必须带 `+1.17.1`（或工程 gradle 里已解析的那一档）
- **Mixin / Loom**：与 1.17.1 Loom 匹配
- **不要**把本目录误当成 1.20.x 变更表

### 数据包兼容性

- 1.16 数据包多数仍可用，但世界高度/洞穴生成相关 json 不要当 1.18 用
- 配方 `type` 字段按本版 wiki，不要抄 1.20 的字段表

## 升级建议

1. **测试优先**：1.16.5 → 1.17.1 先验证注册表仍是 `Registry.*`
2. **映射更新**：同步 Yarn 与 Fabric API
3. **GUI**：`addButton` 改为 `addDrawableChild`
4. **回归测试**：实体属性仍走 `FabricDefaultAttributeRegistry`（1.16.5+ 已有）
