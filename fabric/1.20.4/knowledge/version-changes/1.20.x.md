# Minecraft 1.20.x 版本变更

> 本文件记录从 Minecraft 1.19.x 到 1.20.x 的关键变更，适用于 Fabric 1.20.4。

## 1.20.0 主要变更

### 新增内容

| 内容 | 说明 |
|------|------|
| Camelidae（骆驼）| 新增骆驼实体 |
| Armor Trim（护甲装饰）| 盔甲可以用锻造模板装饰 |
| Recipe Book Toggle | 配方书增加显示/隐藏切换 |
| World Generation Changes | 世界生成调整 |

### 技术变更

| 变更 | 说明 |
|------|------|
| Recipe type 字段 | 配方 JSON 需要明确的 `type` 字段 |
| Loot Table pool rolls | `rolls` 支持范围（`min`、`max`）|
| Advancement trigger | 新增多个 trigger 类型 |
| NBT 格式 | 部分物品的 NBT 格式有变化 |

## 1.20.1 变更

| 变更 | 说明 |
|------|------|
| 修复骆驼相关 Bug | 骆驼骑行稳定性修复 |
| 修复数据包加载问题 | 某些数据包不再导致崩溃 |
| 性能优化 | 改善了大型世界的性能 |

## 1.20.2 变更

| 变更 | 说明 |
|------|------|
| 修复实验性数据格式 | 某些实验性数据格式修复 |
| 新增音乐唱片 | 新增 5 个音乐唱片 |
| 修复村庄生成 | 村庄路径生成优化 |

## 1.20.4 变更

> 本节记录 1.20.4 版本的特定变更，适用于 Fabric 1.20.4。

### 新增内容

| 内容 | 说明 |
|------|------|
| Armor Trim | sentry / dune 等模板属 **1.20.0**，不是 1.20.4 新增 |
| Camelidae 改进 | 骆驼骑行和繁殖机制改进 |
| Smithing Template 变更 | 锻造模板格式有更新 |

### 技术变更

| 变更 | 说明 |
|------|------|
| 护甲装饰模板 ID | 新增模板使用新的命名空间 |
| 骆驼属性调整 | 骆驼生命值、移动速度等属性调整 |
| 数据包验证 | 某些旧版数据包格式验证更严格 |

### 开发者注意事项

- **Yarn 映射**：1.20.4 使用 `yarn:1.20.4+build.X:v2`
- **Fabric API 版本**：使用 `fabric-api:0.XX.X+1.20.4`
- **Mixin 版本**：确保 mixin 版本兼容 1.20.4

## 通用注意事项

### Fabric 开发注意点

- **Yarn 映射版本**：每个 MC 版本需要对应版本的 Yarn 映射
- **Fabric API 版本**：Fabric API 版本需要与 MC 版本匹配（如 `0.91.0+1.20.4`）
- **Mixin 兼容性**：Mixin 版本需要与 MC 版本兼容
- **Loom 版本**：Loom 版本需要支持对应的 MC 版本

### 数据包兼容性

- `type` 字段在 1.20+ 中是**必需**的
- 某些 1.19.x 的配方格式在 1.20.x 中不再有效
- Loot Table 的 `pools` 结构有细微变化

## 升级建议

1. **测试优先**：每次 MC 版本升级前，先在小规模项目中测试
2. **映射更新**：同时更新 Yarn/Parchment 映射版本
3. **API 更新**：Fabric API 也需要对应版本升级
4. **回归测试**：升级后运行完整测试确保功能正常
