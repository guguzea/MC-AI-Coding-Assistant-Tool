# Minecraft 1.16.x 版本变更

> 本文件记录 Minecraft 1.16.x 的关键变更，适用于 Fabric 1.16.5。

## 1.16.x 主要新增内容

| 内容 | 说明 |
|------|------|
| The Nether Update（地狱更新）| 完全重做的下界，包含新生物群系、新方块、新物品 |
| Piglin（猪灵）| 新增猪灵生物群系 |
| Basalt Delta（玄武岩三角洲）| 下界新生物群系 |
| Ancient Debris（远古残骸）| 新增下界矿物，用于锻造 Netherite |
| Netherite（下界合金）| 新增最高级装备材料 |
| Lodestone（指南针框架）| 可让指南针指向特定位置 |
| Respawn Anchor（重生锚）| 下界专用重生道具 |
| Soul Fire（灵魂火）| 下界新增灵魂火焰变体 |
| Soul Speed（灵魂疾行）| 附魔给予灵魂土快速移动 |
| Soul Valley / Soul Sand Valley | 下界新生物群系 |
| Warped Forest / Crimson Forest | 下界新增两个森林生物群系 |
| Hoglin & Zoglin（疣猪兽与僵尸疣猪兽）| 新增下界生物 |
| Strider（炽足兽）| 新增岩浆步行生物 |
| Shroomlight（菌光体）| 新增下界发光方块 |
| Blackstone（黑石）| 下界新增石头变体 |

## 技术变更（1.15.x → 1.16.x）

| 变更 | 说明 |
|------|------|
| `Registries` 类 | 1.17+ 才引入 `Registries` 枚举；1.16.x 使用 `Registry` 静态字段 |
| `Identifier` | 1.16.x 使用 `new Identifier(namespace, path)` 两参数构造 |
| `Tag.Identified` | Fabric API 提供，`Identifier` 方式引用标签 |
| DataGenerator | 1.16.x **没有**内置 DataGenerator，需手动编写 JSON |
| Mixin 配置 | 1.16.x 需要显式 Mixin Plugin（不同于 1.17+）|
| `EntityCategory` | Fabric API 提供，与 `MobCategory` 对应 |
| `FabricBlockSettings` | Fabric API 提供，替代 vanilla `BlockBehaviour.Properties` |

## 通用注意事项

### Fabric 开发注意点

- **Yarn 映射版本**：每个 MC 版本需要对应版本的 Yarn 映射（1.16.5 → `1.16.5+build.10`）
- **Fabric API 版本**：Fabric API 版本需要与 MC 版本匹配（如 `0.42.0+1.16`）
- **Mixin 兼容性**：Mixin 版本需要与 MC 版本兼容
- **Loom 版本**：Loom 版本 `0.10.x` 专为 1.16.x 设计

### 数据包兼容性

- `type` 字段在 1.13+ 中是**必需**的
- 1.16.x 配方格式与 1.15.x 保持一致
- Loot Table 的 `pools` 结构在 1.16.x 中已稳定

## 升级建议

1. **测试优先**：每次 MC 版本升级前，先在小规模项目中测试
2. **映射更新**：同时更新 Yarn/Parchment 映射版本
3. **API 更新**：Fabric API 也需要对应版本升级
4. **回归测试**：升级后运行完整测试确保功能正常
