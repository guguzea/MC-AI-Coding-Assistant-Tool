## 技术变更（1.13.x → 1.14.x）

| 变更 | 说明 |
|------|------|
| `Registries` 类 | 1.17+ 才引入 `Registries` 枚举；1.14.x 使用 `Registry` 静态字段 |
| `Identifier` | 1.14.x 使用 `new Identifier(namespace, path)` 两参数构造 |
| DataGenerator | 1.14.x **没有**内置 DataGenerator，需手动编写 JSON |
| 资源包格式 | `pack.mcmeta` 中 `pack_format` 为 `6` |
| `Block.Settings` | 1.14.x 使用 Minecraft 内置 `Block.Settings`，而非 FabricBlockSettings |
| `Item.Settings` | 1.14.x 使用 Minecraft 内置 `Item.Settings` |
| `FoodComponent` | 1.14.x 使用 Minecraft 内置 `FoodComponent` |
| `EntityCategory` | Yarn 原版枚举（`net.minecraft.entity.EntityCategory`）；不是 Fabric API，也不是 Mojmap `MobCategory` |

## 关键 API 差异（1.14.4 vs 1.16.5）

| 项目 | 1.14.4 | 1.16.5 |
|------|--------|--------|
| Block 构造 | `new Block(Block.Settings.copy(Blocks.STONE))` | `new Block(FabricBlockSettings.copy(Blocks.STONE).build())` |
| Item 构造 | `new Item(new Item.Settings())` | `new Item(new Item.Settings())` |
| Registry.register 返回值 | `T` | `T` |
| Mixin compatibilityLevel | `JAVA_8` | `JAVA_8`（1.16.5 仍是 JAVA_8；JAVA_16 从 1.17.1 起） |
| 文本组件 | `TextComponentString` | `LiteralText` |
| 工具 damage 方法 | `stack.damageItem()` | `stack.damage()` |
| 数据包 Buffer | `PacketBuffer` | `PacketByteBuf` |
| 网络注册 | `ServerSidePacketRegistry.INSTANCE` | `ServerSidePacketRegistry.INSTANCE` |
| 客户端网络入口 | `ClientSidePacketRegistry.INSTANCE` | `ClientSidePacketRegistry.INSTANCE` |

## 通用注意事项

### Fabric 开发注意点

- **Yarn 映射版本**：每个 MC 版本需要对应版本的 Yarn 映射（1.14.4 → `1.14.4+build.4`）
- **Fabric API 版本**：Fabric API 版本需要与 MC 版本匹配（如 `0.4.1+build.18-1.14`）
- **Mixin 兼容性**：Mixin 版本需要与 MC 版本兼容
- **Loom 版本**：Loom 版本 `0.4-SNAPSHOT` 专为 1.14.x 设计
- **Java 版本**：1.14.4 必须使用 Java 8（不能使用 Java 11/16）

### 数据包兼容性

- `type` 字段在 1.13+ 中是**必需**的
- 1.14.x 配方格式与 1.13.x 保持一致
- Loot Table 的 `pools` 结构在 1.14.x 中已稳定

## 升级建议

1. **测试优先**：每次 MC 版本升级前，先在小规模项目中测试
2. **映射更新**：同时更新 Yarn/Parchment 映射版本
3. **API 更新**：Fabric API 也需要对应版本升级
4. **回归测试**：升级后运行完整测试确保功能正常
5. **Java 版本检查**：确认使用 Java 8，勿使用更高版本
