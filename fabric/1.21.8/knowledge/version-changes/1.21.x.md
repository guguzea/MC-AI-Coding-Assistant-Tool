# Minecraft 1.21.4 → 1.21.8 版本变化（Fabric 1.21.8 档）

> 本文件 2026-09-11 新建（用户裁定「补 1.21.x 纪要」）。本档原 `gaps.knowledge` 句「本档语料无可核实主题页可支撑更多短文」措辞过强，已改：语料**有** `develop_porting_index.md`，只是正文 = 改构建脚本三步 + 站外链接。本文件**只用仓内语料与小映射表**，未取任何站外页。
>
> 证据面：`data/fabric_1.21.8/fabric-docs/1.21.8/`（processed 74 页 / raw 67 页）、基线 `data/fabric_1.21.4/`（raw 51 页）、两版 `mappings/yarn-*-tiny.gz`（`yarn-1.21.8+build.1` / `yarn-1.21.4+build.8`）。

> ⚠️ 本区间在本仓是**跨空档**的：官方口径写 1.21.4 → 1.21.8，但中间 1.21.5 / 1.21.6 / 1.21.7 三档本仓**既无规则树也无语料**（见根 `AGENTS.md` fabric 空洞档清单），其变化只能靠该页外链的 NeoForge primer（`:45-47`）——本仓未取，故本文件不写其中的 API 名。

## 2. 构建脚本

CORPUS 同页 `:27-29`，与 1.21.4 档逐字相同的三条：`./gradlew wrapper --gradle-version latest` → 抬 MC / Loader / Loom / Fabric API（推荐改 `gradle.properties`，版本看 fabricmc.net/develop）→ IDE 刷新或 `./gradlew --refresh-dependencies`。

> 本仓不代跑 Gradle（人在环）。本档 `scaffold/` 无 wrapper 三件套 ⇒ 第 1 条在此模板上跑不了，见 `pack.meta.json` `scaffold.gaps`。本档 `scaffold/build.gradle` 的 `java.toolchain` = `JavaLanguageVersion.of(21)`。

## 3. 语料覆盖差：1.21.8 新出的专题入口

raw 67 页 vs 1.21.4 的 51 页 = **仅 1.21.8 有 19 页**、仅 1.21.4 有 3 页（`develop_getting-started_introduction-to-fabric-and-modding` / `develop_getting-started_setting-up-a-development-environment` / `develop_ide-tips-and-tricks`）：

- **getting-started 整族改版**：旧的 `setting-up-a-development-environment` / `ide-tips-and-tricks` 两页消失，换成按 IDE 分线的 `develop_getting-started_{intellij-idea,vscode}_{setting-up,opening-a-project,generating-sources,launching-the-game,tips-and-tricks}` + `develop_getting-started_{index,setting-up,opening-a-project,generating-sources,tips-and-tricks}`。⇒ 「本仓 fabric 各档 getting-started 页名不同构」不是漏抓，是上游 1.21.6+ 重组；跨档比对页名时必须按各版自己的名单查（`list_doc_versions` / `search_fabric_docs`）。
- **新增专题页**：`develop_debugging` · `develop_blocks_block-models` · `develop_items_item-models` · `develop_rendering_world`。

## 4. Yarn 名字实测（三个全新顶层包 + 注册表两处）

CLASS 总数 8850 → 9469。**新增顶层包（1.21.4 全为 0）**：

| 包 | 1.21.8 CLASS 数 | 代表名 |
| --- | --- | --- |
| `net/minecraft/dialog/` | **37** | `DialogTypes` `Dialogs` `DialogActionButtonData` `action/DialogAction` `body/{PlainMessageDialogBody,ItemDialogBody}` `input/{TextInputControl,BooleanInputControl,NumberRangeInputControl,SingleOptionInputControl}` `type/{ConfirmationDialog,NoticeDialog,ServerLinksDialog,DialogListDialog,MultiActionDialog,ColumnsDialog}` |
| `net/minecraft/storage/` | **29** | `ReadView` `WriteView` `NbtReadView` `NbtWriteView` `ReadContext`（+ 一串 `$` 嵌套错误类型） |
| `net/minecraft/gametest/Main` | 1 | 独立入口类（顶层 `gametest` 包 1.21.4 无） |

其它点名变化：

- `net/minecraft/registry/`：仅 1.21.8 有 `ContextSwapper`、`ContextSwappableRegistryLookup`、`entry/LazyRegistryEntryReference`、`tag/DialogTags`；仅 1.21.4 有 `RegistryPair`、`tag/CatVariantTags`。⇒ 注册表「上下文可切换查找」是本区间引入的形态。
- 世界生成：仅 1.21.8 有 `world/gen/feature/FallenTreeFeature{,Config}` 与 `world/gen/treedecorator/{AttachedToLogsTreeDecorator,PlaceOnGroundTreeDecorator}`（1.21.4 无 `treedecorator` 这些名）。
- 配方：`net/minecraft/recipe/TransmuteRecipeResult` 新增；`data/recipe/` 仍 18 个、无成员变化（与 1.21.4 档纪要同数）。

复现（本仓根执行）：

```bash
u() { zcat data/fabric_$1/mappings/yarn-$2-tiny.gz | awk -F'\t' '$1=="CLASS"{print $NF}' | sort -u; }
u 1.21.8+build.1 | grep -c '^net/minecraft/dialog/'    # 37
u 1.21.4+build.8 | grep -c '^net/minecraft/dialog/'    # 0
u 1.21.8+build.1 | grep -c '^net/minecraft/storage/'   # 29
u 1.21.8+build.1 | grep -x  'net/minecraft/registry/RegistryPair' ; echo $?   # 无输出 = 该名字已不在
```
