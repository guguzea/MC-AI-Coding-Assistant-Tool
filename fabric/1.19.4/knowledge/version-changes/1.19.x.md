# Minecraft 1.19.x 版本变更

> 本文件记录从 Minecraft 1.18.x 到 1.19.x 的关键变更，适用于 Fabric 1.19.4。

## 通用注意事项

### Fabric 开发注意点

- **Yarn 映射版本**：每个 MC 版本需要对应版本的 Yarn 映射（1.19.4 使用 `yarn:1.19.4+build.x`）
- **Fabric API 版本**：Fabric API 版本需要与 MC 版本匹配（如 `0.79.1+1.19.4`）
- **Mixin 兼容性**：Mixin 版本需要与 MC 版本兼容
- **Loom 版本**：1.19.x 推荐使用 Loom `0.14-SNAPSHOT`
- **Pack Format**：资源包/数据包使用 pack_format = 9

### 数据包兼容性

- 幽匿感测器系统（Vibration）需要新的数据包支持
- `SpawnGroup` 替代了 `MobCategory`，所有涉及生物生成类别的 API 均已更新
- `EntityDimensions.fixed()` 在 1.19.x 中是创建固定尺寸实体的标准方式
- 某些 1.18.x 的配方格式在 1.19.x 中不再有效

### 生物群系生成注意点

在 `BiomeBuilder` 中使用 `SpawnEntry` 时：

```java
// ✅ 1.19.x 正确写法
SpawnGroup CREATURE = SpawnGroup.CREATURE;  // 使用 SpawnGroup 而非 MobCategory

// ✅ 实体尺寸
EntityDimensions.fixed(0.6f, 1.8f);  // 1.19.x 直接使用 fixed()
```

## 升级建议

1. **测试优先**：每次 MC 版本升级前，先在小规模项目中测试
2. **映射更新**：同时更新 Yarn/Parchment 映射版本
3. **API 更新**：Fabric API 也需要对应版本升级
4. **回归测试**：升级后运行完整测试确保功能正常
5. **注意 SpawnGroup**：所有 `MobCategory` 引用需要改为 `SpawnGroup`
