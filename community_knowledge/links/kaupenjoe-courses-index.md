## 用法

- 写代码前先看目标分支对应工程版本是否一致；跨版本 API 以本档规则 + `search_*_docs` 为准。
- 本库已从其中提炼的自写短文：`authored/custom-commands-brigadier`、`authored/ore-generation-worldgen`、`authored/saveddata-world-persistence`（SavedData 部分另核对 NeoForge 官方文档）、`authored/neoforge-payload-networking`、`authored/data-attachments-vs-alternatives`。

API 细节请用 `search_neoforge_docs` / `search_fabric_docs` / `search_forge_docs`。
