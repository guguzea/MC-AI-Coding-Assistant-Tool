# 代码模式库（community_knowledge/patterns）

本目录是 **Wave D 完成定义** 中的 patterns 框架：可复用的小片段模式（非完整模组）。

与 `knowledge/patterns/` 内容对齐时可互相引用；**验收以本目录为准**。

## 文件约定

- `README.md`：本索引
- `examples/<name>.md`：单模式，建议 **<80 行**
- 每篇含：适用平台/版本、前置 Skill / MCP 工具、最小片段、常见坑
