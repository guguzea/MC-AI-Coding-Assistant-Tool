# Welcome to LiteLoader
Welcome to the LiteLoader developer documentation, these pages are for mod developers who wish to use LiteLoader for their projects, if you're looking to download LiteLoader the head over to the [download page](http://www.liteloader.com/download) instead.

### Getting Started with LiteLoader
Getting started with LiteLoader is quite straightforward, if you are an experienced modder comfortable with using SVN, Eclipse, and setting up multiple projects then you can check out the [Quick Start Guide - for advanced users](dev:quickstart), or for a more in-depth tutorial follow the [Tutorial](dev:tutorial) which covers each of the steps in the Quick Start Guide in more detail.
