# Installing LiteLoader Manually
Installing LiteLoader manually is straightforward, but the precise steps will vary depending on the launcher you are using. To install LiteLoader manually it is not necessary to download any files, all that is required is to make the neccessary edits to the JSON configuration files for the launcher.
