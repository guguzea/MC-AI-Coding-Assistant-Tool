# Installing LiteLoader
As a [info:Tweak](info:Tweak), LiteLoader supports several different installation methods in order to accomodate a variety of environments, the simplest method being to use the [LiteLoader Installer](user:install:installer). If you're not sure what method to use, follow the [Installation Trail](user:install:trail).

* Using the [LiteLoader Installer](user:install:installer)
* Installation if you are using [MultiMC](user:install:multimc)
* Installing [manually](user:install:manual)
* Installing when you [already have Minecraft Forge or FML installed](user:install:forge)

LiteLoader also supports being installed along with other Tweaks such as [Optifine](https://www.minecraftforum.net/forums/mapping-and-modding/minecraft-mods/1272953-optifine) and [Shaders Mod](https://www.minecraftforum.net/forums/mapping-and-modding/minecraft-mods/1286604-shaders-mod), see the link below for instructions:

* [Installing other Tweaks mods (eg. Optifine, ShadersMod)](user:install:othertweaks)
