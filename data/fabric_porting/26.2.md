# Fabric 移植到 26.2

本页是 **26.1→26.2** 线上移植索引的入库摘录，**不是** `data/fabric_26.2` 克隆树。已入库的 `fabric_26.1.2` `develop_porting_index` 标签是 **1.21.11→26.1**。

线上：https://docs.fabricmc.net/develop/porting/index  
博客概述：https://fabricmc.net/2026/06/15/262.html

## 构建

- Loom **1.17**、Gradle **9.5.1**（博客撰写时）
- Fabric Loader 以当时稳定版为准（博客举例 0.19.3）

## 游戏侧（去混淆名）

- 可切换默认 OpenGL 后端与实验性 Vulkan；OpenGL 计划在 Vulkan 稳定后移除。走 Blaze3D，不要直接打 OpenGL。
- 方块/物品 id 分开放在 `BlockIds` / `BlockItemIds` / `ItemIds`；DataGen 用这些 key，不再用 raw `Block`/`Item`。`valueLookupBuilder` 已移除。
- GUI：设屏从 `Minecraft.getInstance().setScreen()` 迁到 `Minecraft.getInstance().gui.setScreen()`。

## Fabric API（博客）

- Loader 0.19.0 + Loom 1.17：enum extensions
- FAPI 0.150.1：tag `fabric:remove`；实验性 Fluid Interaction API
- FAPI 0.152.0：attended client commands（`.requires(FabricClientCommandSource::attended)`）

类名以 `search_fabric_docs` + 反编译为准，本页不是 API 规范。
