# Global Loot Modifier Generation

[Global Loot Modifiers (GLMs)](/docs/1.20.4/resources/server/glm) can be generated for a mod by subclassing `GlobalLootModifierProvider` and implementing `#start`. Each GLM can be added generated by calling `#add` and specifying the name of the modifier and the [modifier instance](/docs/1.20.4/resources/server/glm#igloballootmodifier) to be serialized. After implementation, the provider must be [added](/docs/1.20.4/resources/#data-generation) to the `DataGenerator`.

```java

@SubscribeEvent // on the mod event bus

public static void gatherData(GatherDataEvent event) {

    event.getGenerator().addProvider(

        // Tell generator to run only when server data are generating

        event.includeServer(),

        output -> new MyGlobalLootModifierProvider(output, MOD_ID)

    );

}

// In some GlobalLootModifierProvider#start

this.add("example_modifier", new ExampleModifier(

  new LootItemCondition[] {

    WeatherCheck.weather().setRaining(true).build() // Executes when raining

  },

  "val1",

  10,

  Items.DIRT

));

```
