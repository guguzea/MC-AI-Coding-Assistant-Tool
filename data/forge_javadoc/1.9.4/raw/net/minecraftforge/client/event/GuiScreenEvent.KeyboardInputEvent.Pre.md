# GuiScreenEvent.KeyboardInputEvent.Pre

## Constructors

- `public Pre( GuiScreen gui)`

## Description

This event fires when keyboard input is detected by a GuiScreen. Cancel this event to bypass GuiScreen.handleKeyboardInput() .
