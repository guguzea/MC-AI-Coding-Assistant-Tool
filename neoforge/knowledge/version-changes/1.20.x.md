# 版本变更记录：1.20.x

## 1.20.1 → 1.20.4 迁移注意事项

> 以下为 NeoForge 1.20.4 特有内容。

### 已知差异

| 项目 | Forge 1.20.1 | NeoForge 1.20.4 |
|------|-------------|---------|
| 平台 | Forge | NeoForge（社区分叉） |
| 包名空间 | `net.minecraftforge` | `net.neoforged` |
| 元数据文件 | `mods.toml` | `mods.toml`（1.20.4 仍同名；`neoforge.mods.toml` 从 1.20.6 起） |
| Registry API | 完全一致 | 完全一致 |
| DataGen API | 完全一致 | 完全一致 |
| 构建插件 | ForgeGradle（`net.minecraftforge.gradle`） | ModDevGradle（`net.neoforged.moddev`，本仓 `neoforge/1.20.4/scaffold/build.gradle:4` 钉 `2.0.143`）；官方生成器对同版另给 NeoGradle（`net.neoforged.gradle.userdev`） |

### NeoForge 1.20.4 特有注意事项

#### 包名迁移

绝大多数 `net.minecraftforge` 包迁到 `net.neoforged`（事件总线例外：它换到独立的 `net.neoforged.bus`）：

```java
// Forge 1.20.1
import net.minecraftforge.api.distmarker.Dist;
import net.minecraftforge.common.MinecraftForge;
import net.minecraftforge.eventbus.api.IEventBus;
import net.minecraftforge.fml.common.Mod;
import net.minecraftforge.registries.DeferredRegister;
import net.minecraftforge.registries.ForgeRegistries;

// NeoForge 1.20.4
import net.neoforged.api.distmarker.Dist;
import net.neoforged.neoforge.common.NeoForge;
import net.neoforged.bus.api.IEventBus;               // 不在 net.neoforged.neoforge.eventbus 下
import net.neoforged.neoforge.registries.DeferredRegister;
import net.neoforged.neoforge.registries.NeoForgeRegistries;
```

> 两边都没有 `eventbus.api.Bus` 这个类；`@SubscribeEvent` 在 NeoForge 侧也是 `net.neoforged.bus.api.SubscribeEvent`。
> 名字取自本仓 scaffold 实测 import（`neoforge/<ver>/scaffold/src/main/java/.../ExampleMod.java`）。

#### mods.toml 依赖声明（1.20.4 仍叫 `META-INF/mods.toml`）

官方 1.20.4 scaffold 用 `gradle.properties` 属性占位（实测 `neoforge/1.20.4/scaffold/src/main/templates/META-INF/mods.toml:64-79`）：

```toml
[[dependencies.examplemod]]
modId = "neoforge"            # 注意：不再是 "forge"
type = "required"             # 官方文档列的是 type（默认即 required）
versionRange = "[${neo_version},)"   # 由 gradle.properties 的 neo_version 展开
ordering = "NONE"
side = "BOTH"
```

> 手写死版本也可以，但区间必须是开放下限（`[20.4.237,)` = ≥20.4.237 全接受）；
> 写成 `[20.4.237]` 只匹配这一个补丁版。详见 `neoforge/knowledge/antipatterns/gradle.md`。

## NeoForge 1.20.4 推荐配置

```properties
# 实测 neoforge/1.20.4/scaffold/gradle.properties（官方 MDK-1.20.4-ModDevGradle）
minecraft_version=1.20.4
minecraft_version_range=[1.20.4]
neo_version=20.4.251
loader_version_range=[1,)
parchment_minecraft_version=1.20.4
parchment_mappings_version=2024.04.14
mod_id=examplemod
```

> **没有** `neoforge_version` / `neoforge_version_range` / `mapping_channel` / `mapping_version` / `neoform_version` 这些键。
> 官方 1.20.4 文档（`data/neoforge_1.20.4/.../gettingstarted_modfiles.md`）列的是 `neo_version` 与（可选）`neo_version_range`；
> `mapping_channel` / `mapping_version` 是 ForgeGradle 的叫法，只存在于本仓已废弃的 `neoforge/scaffold/gradle.properties`。
> 映射不写在这份文件里：本仓 8 份 MDG `scaffold/build.gradle` 唯一的映射配置就是 `parchment { mappingsVersion / minecraftVersion }`，没有 `mappings` / `officialMojangMappings` 行（`26.1` 档去混淆，连 parchment 都没有）。

### pack_format

NeoForge 1.20.4 使用 Minecraft 1.20.4 的 pack_format：

| 用途 | pack_format |
|------|------------|
| 资源包 | **22**（一手出处是 **Forge** 1.20.4-49.2.0 MDK 的 `src/main/resources/pack.mcmeta`——`mcp-server/data/mdk-checksums.json:425-437`，`id=forge-1.20.4-forgegradle`，`source=official`；pack_format 是 Minecraft 侧常量，Neo 档同值。详见 `neoforge/knowledge/common/resourcepack-format.md`） |
| 数据包 | 26（**本仓无一手出处**，仓内官方语料只到「As of Minecraft 1.20.2, the pack version is 18」；见 `neoforge/knowledge/common/datapack-format.md`） |

> 两个数字不通用，别把资源包的 22 填进 `data/**/pack.mcmeta`。

## 1.20.x 通用重要变更

#### DeferredRegister 成为唯一推荐

1.20.1 之前使用 `RegistryEvent.Register<T>`，1.18+ 推荐使用 DeferredRegister。

```java
// 1.18+ 推荐方式
public static final DeferredRegister<Block> BLOCKS =
    DeferredRegister.create(BuiltInRegistries.BLOCK, MOD_ID);
BLOCKS.register(modEventBus);

// ❌ 旧方式（1.18 之前）
@SubscribeEvent
public static void register(RegisterEvent event) {
    event.register(BuiltInRegistries.BLOCK).register("my_block", MyBlock::new);
}
```

#### BlockBehaviour.Properties 变化

1.17+ 移除了部分旧方法，使用 `of()` 静态工厂：

```java
// ✅ 推荐（链式调用）
BlockBehaviour.Properties.of(Material.WOOD)
    .mapColor(MapColor.WOOD)
    .strength(2.0f)
    .noOcclusion();

// ❌ 已移除
BlockBehaviour.Properties.create(Material.WOOD)  // create 不存在
```

## NeoForge 特有注意事项

### NeoForge 与 Forge 的差异总结

| 项目 | Forge 1.20.1 | NeoForge 1.20.4 |
|------|-------------|---------|
| 元数据文件 | `mods.toml` | `mods.toml`（1.20.4 仍同名；`neoforge.mods.toml` 从 1.20.6 起） |
| modId 依赖 | `modId="forge"` | `modId="neoforge"` |
| 包名空间 | `net.minecraftforge` | `net.neoforged` |
| Gradle 插件 | `net.minecraftforge.gradle`（ForgeGradle） | `net.neoforged.moddev`（ModDevGradle，本仓 `neoforge/1.20.4/scaffold/build.gradle:4` 用它）或 `net.neoforged.gradle.userdev`（NeoGradle）——**不存在** `neogradle` 这个 id |
| 注册表持有类 | `ForgeRegistries` | `NeoForgeRegistries` |
| 事件总线 | `MinecraftForge.EVENT_BUS` | `NeoForge.EVENT_BUS` |
| 网络包 | `net.minecraftforge.network` | `net.neoforged.neoforge.network` |
| 初始化入口 | `@Mod` 注解类 | `@Mod` + 构造注入 `IEventBus`（禁止 `BuildPlugin` + `init()`） |

### Parchment 映射配置

ModDevGradle 内建 parchment，不需要额外 Gradle 插件，也不写 `mappings` 坐标。本仓 `neoforge/1.20.4/scaffold` 的实测形态（`build.gradle:41-48` + `gradle.properties:10-11`）：

```properties
parchment_minecraft_version=1.20.4
parchment_mappings_version=2024.04.14
```

```groovy
neoForge {
    version = project.neo_version
    parchment {
        mappingsVersion = project.parchment_mappings_version
        minecraftVersion = project.parchment_minecraft_version
    }
}
```

> `2024.04.14` 是 https://maven.parchmentmc.org 上 1.20.4 的实际发布号（2026-09-11 核对 maven-metadata）。
> 旧写法 `mapping_channel=parchment` / `mapping_version=2024.05.05-1.20.4` 属于 ForgeGradle，
> 且那个值既不是发布日期、也不是真实存在的版本串；本仓只有已废弃的 `neoforge/scaffold/gradle.properties` 还留着这类键。
