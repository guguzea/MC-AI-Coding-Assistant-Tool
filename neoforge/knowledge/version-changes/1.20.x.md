# 版本变更记录：1.20.x

## 1.20.1 → 1.20.4 迁移注意事项

> 以下为 NeoForge 1.20.4 特有内容。

### 已知差异

| 项目 | Forge 1.20.1 | NeoForge 1.20.4 |
|------|-------------|---------|
| 平台 | Forge | NeoForge（社区分叉） |
| 包名空间 | `net.minecraftforge` | `net.neoforged` |
| 元数据文件 | `mods.toml` | `neoforge.mods.toml` |
| Registry API | 完全一致 | 完全一致 |
| DataGen API | 完全一致 | 完全一致 |
| Gradle | ForgeGradle | NeoGradle |

### NeoForge 1.20.4 特有注意事项

#### 包名迁移

所有 `net.minecraftforge` 包迁移到 `net.neoforged`：

```java
// Forge 1.20.1
import net.minecraftforge.api.distmarker.Dist;
import net.minecraftforge.common.MinecraftForge;
import net.minecraftforge.eventbus.api.Bus;
import net.minecraftforge.fml.common.Mod;
import net.minecraftforge.registries.DeferredRegister;
import net.minecraftforge.registries.ForgeRegistries;

// NeoForge 1.20.4
import net.neoforged.api.distmarker.Dist;
import net.neoforged.neoforge.common.NeoForge;
import net.neoforged.neoforge.eventbus.api.Bus;
import net.neoforged.neoforge.registries.DeferredRegister;
import net.neoforged.neoforge.registries.NeoForgeRegistries;
```

#### neoforge.mods.toml 依赖声明

```toml
[[dependencies.examplemod]]
modId = "neoforge"           # 注意：不再是 "forge"
mandatory = true
versionRange = "[20.4,)"       # NeoForge 版本范围
```

## 1.20.x 通用重要变更

#### DeferredRegister 成为唯一推荐

1.20.1 之前使用 `RegistryEvent.Register<T>`，1.18+ 推荐使用 DeferredRegister。

```java
// 1.18+ 推荐方式
public static final DeferredRegister<Block> BLOCKS =
    DeferredRegister.create(BuiltInRegistries.BLOCK, MOD_ID);
BLOCKS.register(modEventBus);

// ❌ 旧方式（1.18 之前）
@SubscribeEvent
public static void register(RegisterEvent event) {
    event.register(BuiltInRegistries.BLOCK).register("my_block", MyBlock::new);
}
```

#### BlockBehaviour.Properties 变化

1.17+ 移除了部分旧方法，使用 `of()` 静态工厂：

```java
// ✅ 推荐（链式调用）
BlockBehaviour.Properties.of(Material.WOOD)
    .mapColor(MapColor.WOOD)
    .strength(2.0f)
    .noOcclusion();

// ❌ 已移除
BlockBehaviour.Properties.create(Material.WOOD)  // create 不存在
```

## NeoForge 特有注意事项

### NeoForge 与 Forge 的差异总结

| 项目 | Forge 1.20.1 | NeoForge 1.20.4 |
|------|-------------|---------|
| 元数据文件 | `mods.toml` | `neoforge.mods.toml` |
| modId 依赖 | `modId="forge"` | `modId="neoforge"` |
| 包名空间 | `net.minecraftforge` | `net.neoforged` |
| Gradle 插件 | `net.minecraftforge.gradle` | `neogradle` |
| 注册表持有类 | `ForgeRegistries` | `NeoForgeRegistries` |
| 事件总线 | `MinecraftForge.EVENT_BUS` | `NeoForge.EVENT_BUS` |
| 网络包 | `net.minecraftforge.network` | `net.neoforged.neoforge.network` |
| 初始化入口 | `@Mod` 注解类 | `@Mod` + 构造注入 `IEventBus`（禁止 `BuildPlugin` + `init()`） |

### Parchment 映射配置

```properties
mapping_channel=parchment
mapping_version=2024.05.05-1.20.4
```

NeoForge 不再需要 Parchment Gradle 插件，NeoGradle 原生支持 Parchment。
