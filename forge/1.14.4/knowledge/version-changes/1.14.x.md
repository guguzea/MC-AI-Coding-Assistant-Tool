# 版本变更记录：1.14.x

## 1.14.4 Forge（28.x）重要变更

### DeferredRegister 引入

1.14.x 是 DeferredRegister 引入的版本，推荐使用：

```java
// ✅ 推荐方式（1.14.x+）
public static final DeferredRegister<Block> BLOCKS =
    new DeferredRegister<>(ForgeRegistries.BLOCKS, MOD_ID);

// ❌ 旧方式（已不推荐）
@SubscribeEvent
public void onRegister(RegistryEvent.Register<Block> event) {
    event.getRegistry().register(new Block(...).setRegistryName(...));
}
```

### ForgeGradle 3.x

1.14.x 使用 ForgeGradle 3.x：

```groovy
// build.gradle
plugins {
    id 'net.minecraftforge.gradle' version '[3.0.0,3.2)'
}
```

### 1.14.x 特有配置

```properties
# 1.14.4
minecraft_version=1.14.4
forge_version=28.2.0
forge_version_range=[28,)
mapping_channel=snapshot
mapping_version=20191213.143200
pack_format=5
```

### 迁移注意事项

1. **Java 版本**：1.14.x 支持 Java 8 和 Java 11，推荐使用 Java 11：
   ```groovy
   java.toolchain.languageVersion = JavaLanguageVersion.of(11)
   ```

2. **pack_format**：1.14.4 = 5，与 1.15.x 不同

3. **DeferredRegister**：在 1.14.x 已可用，推荐使用
