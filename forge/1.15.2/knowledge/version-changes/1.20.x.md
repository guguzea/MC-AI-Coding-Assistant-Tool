# 版本变更记录：1.20.x

## 1.20.1 → 1.20.4 迁移注意事项

> 以下为 Forge 1.20.x 特性说明，供跨版本参考。

### 已知差异

| 项目 | 1.20.1 | 1.20.4 |
|------|---------|---------|
| Forge 版本 | 47.x | 48.x |
| Registry API | 完全一致 | 完全一致 |
| DataGen API | 完全一致 | 完全一致 |

### 1.20.x 通用重要变更

#### DeferredRegister 成为唯一推荐

1.20.1 之前使用 `RegistryEvent.Register<T>`，1.18+ 推荐使用 DeferredRegister。

```java
// 1.18+ 推荐方式
public static final DeferredRegister<Block> BLOCKS =
    DeferredRegister.create(ForgeRegistries.BLOCKS, MOD_ID);
BLOCKS.register(modEventBus);

// ❌ 旧方式（1.18 之前）
@SubscribeEvent
public static void register(RegistryEvent.Register<Block> event) {
    event.getRegistry().register(new Block(...).setRegistryName(...));
}
```

#### Block.Properties 变化

1.17+ 移除了部分旧方法，使用 `of()` 静态工厂：

```java
// ✅ 推荐（链式调用）
Block.Properties.of(Material.WOOD)
    .mapColor(MapColor.WOOD)
    .strength(2.0f)
    .noOcclusion();
```

#### EntityType 注册方式

1.18+ 使用 `EntityType.Builder` 注册实体，移除了旧的 `EntityRegistry` 方法。

## 1.15.2 到 1.20.x 的迁移要点

### 主要 API 变化

| 项目 | 1.15.2 | 1.20.x |
|------|---------|---------|
| 方块属性 | `Properties.create(Material)` | `Block.Properties.of(Material)` |
| 方块实体 | `TileEntity` | `BlockEntity` |
| 工具材料 | `IItemTier` | `Tier` |
| 流体 | `Fluid` | `FlowingFluid` + `FluidType` |
| 数据生成 | `GatherDataEvent` | 基本一致 |
| 网络 | `SimpleChannel` | 基本一致 |

### 迁移建议

1. **方块属性**：从 `Properties.create()` 迁移到 `Block.Properties.of()`
2. **方块实体**：从 `TileEntity` 迁移到 `BlockEntity`
3. **工具材料**：从 `IItemTier` 迁移到 `Tier`
4. **Java 版本**：从 Java 8（1.15.2 `gettingstarted.md:14`）升到 Java 17（1.20.1 `gettingstarted.md:15`）；中间 1.17.1 起要 Java 16、1.18.2 起要 Java 17
5. **Gradle**：从 Gradle 7.x 升级到 Gradle 8.x
6. **ForgeGradle**：从 4.x 升级到 6.x
