# 真实开源项目参考

> 可直接作为 Minecraft Mod 开发的参考模板。

---

| 项目 | 平台 | 亮点 | 链接 |
|------|------|------|------|
| MultiLoader-Template | Fabric + NeoForge | 最流行的 Java 多 Loader 模板，完整项目结构 | https://github.com/jaredlll08/MultiLoader-Template |
| Create Multiloader Addon Template | Fabric + NeoForge | `@ExpectPlatform` 大量使用示例 | https://github.com/Fabricators-of-Create/create-multiloader-addon-template |
| Architectury Example Mod | Fabric + Forge + NeoForge | 官方示例，涵盖所有基础功能（注册、事件、网络） | https://github.com/architectury/architectury-example-mod |
| Firmament | Architectury (多平台) | Kotlin 实现 ExpectPlatform 示例 | https://git.nea.moe/github/Firmament |
| mc-mod-porter | Fabric + NeoForge | 带知识库的 auto-porter CLI 工具 | https://github.com/reqsery/mc-mod-porter |
| Forge Config API Port | Fabric + Forge + NeoForge | 统一配置 API，支持 multiloader | https://www.curseforge.com/minecraft/mc-mods/forge-config-api-port |
| Larsen's Mods 教程 | Fabric + NeoForge | 完整 Architectury 教程 | https://larsensmods.de/architectury-guide/ |

## 使用建议

- **学习 Architectury 基础** → 从 `architectury-example-mod` 开始
- **快速搭建项目** → 使用 `MultiLoader-Template`
- **学习 ExpectPlatform 模式** → 参考 `create-multiloader-addon-template`
- **理解完整迁移流程** → 阅读 `mc-mod-porter` 的源码和知识库
