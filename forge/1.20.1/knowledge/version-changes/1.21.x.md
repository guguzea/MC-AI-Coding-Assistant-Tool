# Minecraft 1.21.x 变更摘要（Forge/NeoForge）

> 正式 API 以 `search_neoforge_docs` / `search_docs` 为准；本文为速查专章。

## 注册与数据

- **Data Components** 逐步替代部分 ItemStack NBT 用法（NeoForge 文档 data attachments / components）。
- **Creative Mode Tab**：注册 API 与 1.20.1 不同，勿照搬旧 DeferredRegister 示例。
- **ResourceLocation** → 多数场景使用 `ResourceLocation.fromNamespaceAndPath`。

## 网络

- NeoForge 1.21 推荐 **CustomPacketPayload + StreamCodec**，替代部分 SimpleChannel 手写 encode/decode。
- 使用 MCP `generate_network_packet` 时选 `neoforge_1.21` 平台。

## 映射

- 官方 **Mojang mappings** 为默认；Yarn 仍可用于 Fabric。
- `convert_mapping` 的 `to=mojang` 仍为 Tiny official 短名，不是可读 FQCN。

## 移植

- 自 1.20.1 Forge 迁移：优先 `analyze_porting_path` + `get_migration_guide`（`1.20.4->1.21.1`、`forge->neoforge`）。
- 包名 `net.minecraftforge` → `net.neoforged`（NeoForge）。

## 性能

- 减少每 tick 全表扫描；方块实体用 `setChanged()` 与 lazy sync。
- 客户端仅 `@OnlyIn(Dist.CLIENT)` 注册渲染与粒子。
