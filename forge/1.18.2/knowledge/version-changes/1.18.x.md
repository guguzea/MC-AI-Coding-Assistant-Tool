# 版本变更记录：1.18.x

## 1.18.2 Forge（40.x）概述

> Forge 1.18.2 是 Minecraft Caves & Cliffs 更新的一部分，引入了大量世界生成和 API 变更。

## 核心变更

### 世界高度变化

| 版本 | 世界高度 |
|------|----------|
| 1.17.x | 0 ~ 256 |
| **1.18.x** | **-64 ~ 320** |

```java
// ✅ 1.18.2 世界高度
LevelHeightAccessor world = level;
int minBuildHeight = world.getMinBuildHeight();  // -64
int maxBuildHeight = world.getMaxBuildHeight();  // 320
```

### 注册表字段名变更

| 注册内容 | 旧名称（1.17.x） | 新名称（1.18.x） |
|----------|-----------------|-----------------|
| 方块实体 | `BLOCK_ENTITIES` | `BLOCK_ENTITIES`（两代字段名相同，不要写成 BLOCK_TILES） |
| 实体类型 | 未核实（本仓无 1.17.1 ForgeRegistries 字段清单） | `ENTITIES`（本档正名，出处 .cursor/rules/01-registry.mdc:27；`ENTITYTYPES` 在任何 Forge 版本都不存在，1.19 起改名 `ENTITY_TYPES`） |
| 菜单类型 | — | `CONTAINERS` |
| 流体类型 | — | **1.18.x 没有流体类型注册表**：`FLUIDTYPES` 与 `FLUID_TYPES` 在 1.18.2 都不存在（一手坐实，见下表注），流体走 `FLUIDS` |

> **本表取证状态（2026-09-24 一手坐实，勿删）**：本仓 `data/**` 语料逐字支撑的 `ForgeRegistries` 字段仍只有 `BLOCKS` / `ITEMS`（`data/forge_1.18.2/forge-docs/1.18.2/processed/concepts_registries.md:24,96`）；`data/**` 是上游逐字语料，本档一个字节都不改。其余行（`BLOCK_ENTITIES` / `ENTITIES` / `CONTAINERS` / `SOUND_EVENTS` / `PARTICLE_TYPES` / `FLUIDS`）现已由**官方构件逐字**坐实：1.18.2-40.1.80 源码 `ForgeRegistries.java`（157 行）＋ 1.18.2-40.3.12 universal jar `javap -p`（41 行、注册表字段 32 个）两 build 两机制互证，as-of 2026-09-24，档位「外部-only（官方构件逐字，仓内无副本 ⇒ 复核需自备 jar）」。**「流体类型」那一行旧写法是事实错、不是未核实**：1.18.2 既无 `FLUIDTYPES` 也无 `FLUID_TYPES`（`FluidType` + `FLUID_TYPES` 是 **1.19+** 才有），流体注册表叫 `FLUIDS`；旧状态是它与本包 `.cursor/skills/mc-fluid/SKILL.md:22`、`:102` 的 ❌ 禁令**同名并存、未裁定**，现**判给禁令侧**、该行已删改。坐实入口（已验证可用）：`unzip -p <40.1.80-sources.jar> net/minecraftforge/registries/ForgeRegistries.java` ＋ `javap -p -classpath <40.3.12-universal.jar> net.minecraftforge.registries.ForgeRegistries`；`query_loader_api` 摘要面 `fields` 恒 0，取不到字段名。同名并存也见 `knowledge/antipatterns/registry.md` 与 `knowledge/common/glossary.md` 的同表注。

### DeferredRegister 成熟

1.18+ 是 DeferredRegister 完全成熟的版本：

```java
// ✅ 推荐方式
public static final DeferredRegister<Block> BLOCKS =
    DeferredRegister.create(ForgeRegistries.BLOCKS, MOD_ID);
BLOCKS.register(modEventBus);
```

### pack_format 变化

| 版本 | 资源包 | 数据包 | 官方出处（MDK `src/main/resources/pack.mcmeta`，sha256 见 `mcp-server/data/mdk-checksums.json`） |
|------|--------|--------|----------|
| 1.17.x | 7 | 7 | 1.17.1-37.1.1 MDK 只有一个 `pack_format: 7`（1.18 前两类包同号） |
| **1.18.x** | **8** | **9** | 1.18.2-40.3.0 MDK 起**分家**：`forge:resource_pack_format: 8` + `forge:data_pack_format: 9`（外层 `pack_format: 9`） |
| 1.19 – 1.19.2 | 未核实 | 未核实 | 本仓无该小版本的 MDK 实测；原表把「1.19.x = 9」当新号是串位 —— 9 是 1.18 的数据包号 |
| 1.19.3 – 1.19.4 | 13 | 12 | 1.19.4-45.4.0 MDK：外层 `pack_format: 13`（资源）+ `forge:server_data_pack_format: 12` |
| 1.20 – 1.20.1 | 15 | 15 | 1.20.1-47.4.10 MDK = `pack_format: 15` |

## 迁移注意事项

### 从 1.17.x 迁移到 1.18.x

1. **世界高度**：检查所有 Y 坐标相关代码
2. **ForgeRegistries 字段**：更新字段名
3. **ForgeGradle**：从 FG4 升级到 FG5
4. **Java**：确保使用 Java 17

### Java 版本

```groovy
// ✅ 必须配置 Java 17
java.toolchain.languageVersion = JavaLanguageVersion.of(17)
```
