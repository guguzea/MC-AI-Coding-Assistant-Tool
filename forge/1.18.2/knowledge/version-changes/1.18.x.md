# 版本变更记录：1.18.x

## 1.18.2 Forge（40.x）概述

> Forge 1.18.2 是 Minecraft Caves & Cliffs 更新的一部分，引入了大量世界生成和 API 变更。

## 核心变更

### 世界高度变化

| 版本 | 世界高度 |
|------|----------|
| 1.17.x | 0 ~ 256 |
| **1.18.x** | **-64 ~ 320** |

```java
// ✅ 1.18.2 世界高度
LevelHeightAccessor world = level;
int minBuildHeight = world.getMinBuildHeight();  // -64
int maxBuildHeight = world.getMaxBuildHeight();  // 320
```

### 注册表字段名变更

| 注册内容 | 旧名称（1.17.x） | 新名称（1.18.x） |
|----------|-----------------|-----------------|
| 方块实体 | `BLOCK_ENTITIES` | `BLOCK_ENTITIES`（两代字段名相同，不要写成 BLOCK_TILES） |
| 实体类型 | `ENTITIES` | `ENTITYTYPES` |
| 菜单类型 | — | `CONTAINERS` |
| 流体类型 | — | `FLUIDTYPES` |

### DeferredRegister 成熟

1.18+ 是 DeferredRegister 完全成熟的版本：

```java
// ✅ 推荐方式
public static final DeferredRegister<Block> BLOCKS =
    DeferredRegister.create(ForgeRegistries.BLOCKS, MOD_ID);
BLOCKS.register(modEventBus);
```

### ForgeGradle 版本

| Minecraft 版本 | ForgeGradle 版本 |
|---------------|------------------|
| 1.16.x | FG3 |
| 1.17.x | FG4 |
| **1.18.x** | **FG5** |
| 1.20.x | FG6 |

```groovy
// build.gradle
id 'net.minecraftforge.gradle' version '[5.1.2,5.2)'
```

### pack_format 变化

| 版本 | 资源包 | 数据包 | 官方出处（MDK `src/main/resources/pack.mcmeta`，sha256 见 `mcp-server/data/mdk-checksums.json`） |
|------|--------|--------|----------|
| 1.17.x | 7 | 7 | 1.17.1-37.1.1 MDK 只有一个 `pack_format: 7`（1.18 前两类包同号） |
| **1.18.x** | **8** | **9** | 1.18.2-40.3.0 MDK 起**分家**：`forge:resource_pack_format: 8` + `forge:data_pack_format: 9`（外层 `pack_format: 9`） |
| 1.19 – 1.19.2 | 未核实 | 未核实 | 本仓无该小版本的 MDK 实测；原表把「1.19.x = 9」当新号是串位 —— 9 是 1.18 的数据包号 |
| 1.19.3 – 1.19.4 | 13 | 12 | 1.19.4-45.4.0 MDK：外层 `pack_format: 13`（资源）+ `forge:server_data_pack_format: 12` |
| 1.20 – 1.20.1 | 15 | 15 | 1.20.1-47.4.10 MDK = `pack_format: 15` |

## 迁移注意事项

### 从 1.17.x 迁移到 1.18.x

1. **世界高度**：检查所有 Y 坐标相关代码
2. **ForgeRegistries 字段**：更新字段名
3. **ForgeGradle**：从 FG4 升级到 FG5
4. **Java**：确保使用 Java 17

### Java 版本

```groovy
// ✅ 必须配置 Java 17
java.toolchain.languageVersion = JavaLanguageVersion.of(17)
```
