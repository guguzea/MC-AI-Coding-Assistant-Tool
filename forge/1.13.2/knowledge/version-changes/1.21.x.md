# 版本变更记录：1.21.x

> 本档规则树只适用于 **Forge 1.13.2**。本章记录 **Minecraft 1.21.x**。
>
> ⚠️ **本仓没有 Forge 1.21.x 文档语料**：`list_forge_versions` 最新为 **1.20.4**，且 notes 明示 `forge/1.21.1` 是 draft（无 00–10 规则树、不在文档版本清单）。1.21.x 的 API 事实**一律属 NeoForge 侧**，本章每条都标注来源；查文档请用 `search_neoforge_docs`（`list_neoforge_versions` 含 `1.21.1 / 1.21.3 / 1.21.5 / 1.21.8 / 1.21.10 / 1.21.11 / 26.1`）。

## 平台先换，再谈版本

来自本仓 porting 笔记（`forge/1.17.1` 与 `forge/1.16.5` 两档的 `knowledge/porting/02-version-migration.md` 同段）与 `neoforge/*/AGENTS.md`：

- Forge 自 1.20.2 起不再是主线，社区分叉为 **NeoForge**；本仓版本对照表把 1.21.x 的加载器记为 **NeoForge 21.x**。
- 包名 `net.minecraftforge.*` → `net.neoforged.*`（全局替换）。
- 元数据文件 `META-INF/mods.toml` → `neoforge.mods.toml`（`neoforge/1.21.11/AGENTS.md`、`neoforge/1.21.1` 档 Skill 一致）。
- `RegistryObject<T>` → `DeferredHolder<T, T>`（泛型收紧）。
- 构建：NeoGradle / ModDevGradle 取代 ForgeGradle，移除 `fg.deobf`。
- Java：**21**（`neoforge/1.21.11/AGENTS.md`；porting 对照表亦记 26.1 之前的版本用 Java 21）。

## 注册（NeoForge 1.21.1）

来源：`neoforge/1.21.1/.cursor/rules/01-registry.mdc`（该档注明取自 `docs.neoforged.net/docs/1.21.1/concepts/registries/`）：

```java
public static final DeferredRegister.Blocks BLOCKS =
    DeferredRegister.createBlocks(ExampleMod.MODID);
public static final DeferredRegister.Items ITEMS =
    DeferredRegister.createItems(ExampleMod.MODID);

// 产出类型是 DeferredBlock / DeferredItem / DeferredHolder，不再假定 Forge 的 RegistryObject
```

- 备选事件仍是 **`RegisterEvent`（mod bus，构造之后）**；运行时查询用 vanilla `Registry`，不要把 `DeferredRegister` 当运行时 map。
- 自定义 datapack registry 走 `ResourceKey.createRegistryKey(ResourceLocation.fromNamespaceAndPath("yourmodid", "spells"))` 一类写法。

## ResourceLocation：构造器已私有

来源：`get_neoforge_doc_full --id=primer/1.21 --version=1.21.1`（**注意 `get_neoforge_doc_full` 必须带 `--version`**）。 primer 原文列出：

| 旧写法 | 1.21 替代 |
|--------|-----------|
| `new ResourceLocation(String, String)` | `ResourceLocation.fromNamespaceAndPath(String, String)` |
| `new ResourceLocation(String)` | `ResourceLocation.parse(String)` |
| `new ResourceLocation("minecraft", String)` | `ResourceLocation.withDefaultNamespace(String)` |
| `ResourceLocation.of` | `ResourceLocation.bySeparator` |
| `ResourceLocation.isValidResourceLocation` | 已移除 |

## 数据组件（Data Components）

同 primer 页出现：`net.minecraft.core.component.DataComponentMap`（含 `makeCodec` / `makeCodecFromMap`）、`DataComponentPatch`、`net.minecraft.core.component.TypedDataComponent#createUnchecked`、`net.minecraft.commands.arguments.item.ItemInput` 改为接收 `DataComponentPatch`。

- 结论：ItemStack 上的自定义数据走**数据组件**，Forge 1.13.2 时代的 `NBTTagCompound` 直读写法不再对应任何 1.21 API。
- NeoForge 侧「实体/方块等对象上的自定义数据」由 **`AttachmentType`** 承担（来源：`neoforge/1.21.1` 档 `mc-capability` Skill 名册；该项未展开核实，动代码前查 `search_neoforge_docs`）。

## 网络（NeoForge 1.21）

来源：`get_neoforge_doc_full --id=networking/payload --version=1.21.1`，该页确实出现 `CustomPacketPayload`、`PayloadRegistrar`、`RegisterPayloadHandlersEvent`、`StreamCodec`、`IPayloadContext`。

- 1.21 是**复数**形态 `RegisterPayloadHandlersEvent` + `PayloadRegistrar`；NeoForge 1.20.4 是**单数** `RegisterPayloadHandlerEvent` + `IPayloadRegistrar`（`neoforge/1.20.4/AGENTS.md`）。两档不要互抄。
- Forge 的 `SimpleChannel` 手写 encode/decode 在 1.21 NeoForge 侧被 `CustomPacketPayload` + `StreamCodec` 取代。
- MCP `generate_network_packet` 选 `neoforge_1.21` 平台（`forge/1.20.1/knowledge/version-changes/1.21.x.md`）。

## 其他 1.21 断点（primer 页实证）

- `net.minecraft.world.item.CreativeModeTab#getBackgroundSuffix` → `getBackgroundTexture`；创造标签页注册 API 与 1.20.1 不同，别照搬旧 DeferredRegister 示例。
- `net.minecraft.data.loot.BlockLootSubProvider` 改为接收 `HolderLookup$Provider`，常量 `HAS_SILK_TOUCH` → 方法 `hasSilkTouch`。
- 映射：官方 Mojang 名为默认（`forge/1.20.1/knowledge/version-changes/1.21.x.md`）。26.1 才是「游戏 jar 已去混淆」那一档，与 1.21.x 不是一档。

## 对本档（forge/1.13.2）工程的影响

### A. 仍留在 1.13.2：本章全部名字都是禁止项

`ResourceLocation.parse` / `fromNamespaceAndPath`、`DeferredHolder` / `DeferredRegister.createBlocks`、`neoforge.mods.toml`、`CustomPacketPayload` / `StreamCodec` / `PayloadRegistrar`、`DataComponentPatch` 在 1.13.2 **一个都不存在**。本档形态仍是 `new ResourceLocation(MOD_ID, "x")` + `setRegistryName(...)` + `RegistryEvent.Register<T>` + `SimpleChannel` + `NBTTagCompound`，且 mod id 禁止连字符。

### B. 1.13.2 → 1.21.x 是「两次移植」叠加

1. **版本线**：1.13.2 → 1.16.5 → 1.18.2 → 1.20.1（清掉同目录 `1.19.x.md` / `1.20.x.md` 的 B 节断点：Java 8→17、FG3→FG6、MCP SRG→official/Parchment、`TileEntity`→`BlockEntity`、`NBTTagCompound`→`CompoundTag`、`Container`→`AbstractContainerMenu`、`ItemGroup`→`CreativeModeTab`、`isRemote`→`isClientSide`、`Properties.create(Material)`→无参 `of()`）。
2. **平台线**：Forge → NeoForge（包名、元数据文件名、`RegistryObject`→`DeferredHolder`、构建插件、`ResourceLocation` 构造方式、网络 payload 化、数据组件化）。
   Java 还要 17 → **21**。

不要试图一步做完：第 2 步的名字如果按 Forge 记忆补，会得到编译不过的「四不像」。分析用 `analyze_porting_path`，脚手架用 `port_project`（默认 dryRun，写盘需用户确认）。

### C. 工具边界

- `query_api` 索引约 **1.16.5–1.20.4**，**不含 1.21.x**：拿它查 1.21 类名一定 `found:false`，那不代表游戏里没有这个类。
- 1.21.x 事实只能 `search_neoforge_docs` / `get_neoforge_doc_full --version=1.21.1`（或对应精确版本）；`search_forge_docs` 在 1.21.x 无版可查。
- 本仓 **禁止**为 1.21.x 克隆 Forge 规则树；`forge/1.21.1` 只有 draft，session 会 `PACK_NOT_FOUND`。
