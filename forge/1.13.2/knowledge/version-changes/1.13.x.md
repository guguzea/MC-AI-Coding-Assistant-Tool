# 版本变更记录：1.13.x

## Forge 1.13.2 重要变更

### Modules 系统

Forge 25.0+ 引入了模块系统，这是 1.13 的重要特性：

```
# mods.toml 中
modLoader="javafml"
loaderVersion="[25,)"  # 25.0+ 支持模块系统
```

### 注册系统

1.13.2 使用 `@EventBusSubscriber` + `RegistryEvent.Register<T>` 模式：

```java
// 正确方式
@Mod(ExampleMod.MOD_ID)
public class ExampleMod {
    public ExampleMod() {
        MinecraftForge.EVENT_BUS.register(this);
    }

    @SubscribeEvent
    public void onBlocksRegistry(RegistryEvent.Register<Block> event) {
        event.getRegistry().register(
            MY_BLOCK.setRegistryName(new ResourceLocation(MOD_ID, "my_block"))
        );
    }
}
```

### Block.Properties

1.13 使用 `Block.Properties.create(Material)` 而非 1.16+ 的 `BlockBehaviour.Properties.of()`（1.16.5 文档名是 `AbstractBlock.Properties.of`，1.17+ 才是 `BlockBehaviour.Properties.of`）：

```java
// 1.13.2
new Block(Block.Properties.create(Material.ROCK)
    .hardnessAndResistance(1.5f, 6.0f))

// 1.16+（不同）
new Block(BlockBehaviour.Properties.of(Material)
    .strength(1.5f, 6.0f))
```

本档 `Material` 共 39 个常量（2026-09-11 javap 实测映射后 jar）：石头质感用 `Material.ROCK`，**没有** `Material.STONE`（`Material.STONE` 至少要到 1.18.2 那一代才可用——本仓库 `forge/1.18.2` scaffold 以 `of(Material.STONE, MaterialColor.STONE)` 真机跑通过）。

### TileEntity vs BlockEntity

1.13–1.16.5 使用 `TileEntity`，1.17+ 使用 `BlockEntity`（命名变更）：

| 1.13–1.16.5 | 1.17+ |
|-------|--------|
| `TileEntity` | `BlockEntity` |
| `ITileEntityProvider` | `EntityBlock` |
| `createNewTileEntity()` / `createTileEntity()` | `newBlockEntity()` |

### NBT vs CompoundTag

1.13–1.16.5 使用 `NBTTagCompound`，**1.17+** 使用 `CompoundTag`（重命名）：

| 1.13–1.16.5 | 1.17+ |
|-------|--------|
| `NBTTagCompound` | `CompoundTag` |
| `NBTTagInt` | `IntTag` |
| `readFromNBT()` / `read()` | `load()` |
| `writeToNBT()` | `saveAdditional()` |

### 网络

1.13 **已经**使用 `SimpleChannel`（不要写成 1.12 的 `SimpleNetworkWrapper`）：

| 1.12（不要抄进本档） | 1.13 |
|-------|--------|
| `SimpleNetworkWrapper` + `IMessage` | `SimpleChannel` + encoder/decoder/consumer |
| `sendTo` / `sendToAll` | `PacketDistributor` + `INSTANCE.send` |

### GUI

1.13–1.16.5 使用 `Container` + `ContainerType`（+ `IGuiHandler`），1.17+ 使用 `AbstractContainerMenu` + `MenuType`：

| 1.13–1.16.5 | 1.17+ |
|-------|--------|
| `Container` | `AbstractContainerMenu` |
| `IGuiHandler` | `MenuProvider` |
| `ContainerType` | `MenuType` |
| `GuiScreen` | `AbstractContainerScreen` |

### ItemGroup vs CreativeModeTab

| 1.13–1.16.5 | 1.17+ |
|-------|--------|
| `ItemGroup` | `CreativeModeTab` |
| `ItemGroup.MISC` | `CreativeModeTab.TAB_MISC` |
| `.group(ItemGroup)` | `.tab(CreativeModeTab)` |

### Dist 检查

`world.isRemote`（1.13–1.15.2）vs `world.isClientSide`（1.16+）

### Mappings

1.13 使用 MCP SRG 格式：
- `mapping_channel=mcp`
- `mapping_version=1.13.2`

### Java 版本

| 版本 | Java 要求 |
|------|----------|
| 1.13 | Java 8 |
| 1.20.1 | Java 17 |
