# 版本变更记录：1.20.x

> 本档规则树只适用于 **Forge 1.13.2**。本章记录 **Minecraft 1.20.x（Forge 47.x / 48.x）** 的变更：
> 一是给「本档工程要不要往 1.20.x 搬」列断点，二是划清「留在 1.13.2 时不能写什么」。
> 1.13.2 → 1.20.x 之间还叠着 1.15+/1.17+/1.19+ 三批重命名，先看同目录 `1.19.x.md` 的对照表，本章不重复。

## 1.20.x 通用变更

### BlockBehaviour.Properties：1.20 起不带 Material

逐版比对 `query_api --class='BlockBehaviour$Properties'`：

| 版本 | `of` 重载 |
|------|-----------|
| 1.18.2 | 4 个，含 `of(Material)`、`of(Material, DyeColor)`、`of(Material, Function)` |
| 1.19.4 | 4 个，同上（该版官方文档示例仍写 `Properties.of(Material.STONE)`） |
| **1.20.1** | **只剩 1 个无参 `of()`** |
| 1.20.4 | 同样只剩无参 `of()` |

```java
// ✅ 1.20.x（已核实：1.20.1 索引里 of 的 descriptor 为 ()L…BlockBehaviour$Properties;）
BlockBehaviour.Properties.of()
    .mapColor(MapColor.WOOD)
    .strength(2.0f)
    .noOcclusion();

// ❌ 1.20.x 索引里查不到
BlockBehaviour.Properties.create(Material.WOOD)   // create 不存在（1.17 前形态）
BlockBehaviour.Properties.of(Material.WOOD)       // 1.20.1 起该重载不在索引中
```

> `forge/1.19.4/knowledge/version-changes/1.20.x.md` 把 `of(Material.WOOD)` 当成 1.20.x 推荐写法，那是 **≤1.19.x** 的形态，别当 1.20.x 依据。
> 未核实：1.20.1 中 `net.minecraft.world.level.material.Material` 类本身是否仍存在（索引里简名 `Material` 只命中客户端 `net.minecraft.client.resources.model.Material`）；本章只断言「带 Material 的 `Properties` 工厂重载不在 1.20.1 索引中」。

### 注册：DeferredRegister 是唯一推荐

```java
// 1.20.x 推荐
public static final DeferredRegister<Block> BLOCKS =
    DeferredRegister.create(ForgeRegistries.BLOCKS, MOD_ID);
BLOCKS.register(modEventBus);   // mod bus，构造器内调用
```

`ForgeRegistries.BLOCKS` / `DeferredRegister.create` / `RegistryObject` / `FMLJavaModLoadingContext.get().getModEventBus()` 均在 1.19.4 官方文档 `concepts_registries` 页出现，1.20.1 沿用（`forge/1.20.1/knowledge/version-changes/1.20.x.md`）。

### 实体 / GUI / DataGen

- 实体：`EntityType.Builder.of()`（`query_api` 在 1.18.2 与 1.20.1 都返回 `of` / `sized` / `immuneTo` / `build`，这条线自 1.18 起未断）。
- GUI：`AbstractContainerMenu` + `MenuType`（1.17+ 形态，本档 1.13.2 用的是 `Container` + `ContainerType`）。
- DataGen：`RecipeProvider` / `LootTableProvider` API 与 1.19.x 基本一致（`forge/1.20.1/knowledge/version-changes/1.19.x.md` 迁移注意事项）。

## Forge 1.20.1 与 1.20.4

| 项目 | 1.20.1 | 1.20.4 |
|------|--------|--------|
| Forge | 47.x | 48.x |
| Registry API | 完全一致 | 完全一致 |
| DataGen API | 完全一致 | 完全一致 |

（表来自 `forge/1.20.1/knowledge/version-changes/1.20.x.md`。）

**1.20.2 是分叉点**：本仓 porting 笔记记「Forge 1.20.2 之后不再更新，社区分叉为 NeoForge」，并列出 `net.minecraftforge` → `net.neoforged`、`modId="forge"` → `modId="neoforge"`、`RegistryObject<T>` → `DeferredHolder<T, T>`、NeoGradle 7 引入且移除 `fg.deobf`。详见同目录 `1.21.x.md`；**不要**照 Forge 1.20.1 的示例直接编 1.20.2+ 工程。

### 1.20.1 已知坑：ArmorMaterial 与 DeferredRegister

`forge/1.20.1/knowledge/version-changes/1.20.x.md` 记：1.20.6 才修复 `DeferredRegister` 在特定时机对 `ArmorMaterial` 的兼容性问题（该稿引用 issue **#9961**；issue 标题本身 **未核实**）。1.20.1 上的规避写法：

```java
// ✅ 先定义完整 ArmorMaterial，再在 lambda 里引用
public static final RegistryObject<Item> COPPER_HELMET = ARMOR.register("copper_helmet",
    () -> new ArmorItem(COPPER_ARMOR_MATERIAL, ArmorItem.Type.HELMET, new Item.Properties()));
```

`pack_format`：1.20 – 1.20.1 = **15**（本仓 1.18.2 / 1.19.4 两档对照表一致）。

## 对本档（forge/1.13.2）工程的影响

### A. 仍留在 1.13.2：本章相关禁止项

`BlockBehaviour`（本档是 `Block.Properties`）、`Properties.of()`（本档是 `Properties.create(Material)`）、`strength` / `destroyTime`（本档 `hardnessAndResistance`）、`DeferredRegister` / `RegistryObject` / `ForgeRegistries.Keys`（本档 `RegistryEvent.Register<T>` + `setRegistryName(new ResourceLocation(MOD_ID, "x"))`）、`MenuType` / `AbstractContainerMenu`、`CreativeModeTab`、`CompoundTag`、`MapColor`、`java.toolchain.languageVersion = JavaLanguageVersion.of(17)`（本档 Java 8 / FG 3.x / Gradle 6.x）。

### B. 升到 1.20.x 必须付的账

1. 先把 `1.19.x.md` B 节的 6 条断裂点全清掉（Java、FG/Gradle、mappings、注册形态、批量重命名、世界高度）。
2. 追加：`Properties` 工厂不再带 `Material` → 改用无参 `of()` + `mapColor`。
3. 追加：`mods.toml` 形态在 1.20.x 仍支持，但 **1.20.2+ 走 NeoForge** 就要换包名与 `neoforge.mods.toml`，属于换平台而非换版本号。
4. 追加：`gradle.properties` 与 `pack_format`（1.13.2 → 15）同步更新；本仓没有 1.13.2 的 `pack_format` 记录，**未核实**，按 `pack.mcmeta` 官方页核。

### C. 工具边界

`query_api` 覆盖约 1.16.5–1.20.4，本章所有 1.20.x 结论都可用 `--version=1.20.1` / `1.20.4` 复核；1.13.2 侧只能用 `search_forge_docs --version=1.13.2`。本仓 **无** Forge 1.21.x 文档语料（`list_forge_versions` 最新为 1.20.4）。
